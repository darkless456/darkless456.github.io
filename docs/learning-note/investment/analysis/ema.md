# 双隧道交易判断趋势及买卖点

## EMA & MA 区别

- EMA（指数移动平均），近期数据权重更高，反应更快，适合捕捉**短期变化**
- MA（简单移动平均），所有数据权重相同，计算简单，反应更慢，适合看**长期趋势**

## 隧道交易法

趋势线：

- 短期，8 13 21 均线
- 中期，55 均线
- 长期，144 169 288 338 均线

两条隧道：

- 1号隧道，144ema 169ema
- 2号隧道，288ema 338ema

判断趋势：

- 上涨趋势，1号在2号上方，且两条隧道处于上升状态
- 下降趋势，1号在2号下方，且两条隧道处于下降状态
- 震荡（不明）趋势，1号在2号互相纠缠，且趋于水平状态

备注：

- 高流动性，盘子大的资产适合
- 回踩隧道，开始做多，加仓，回踩2号隧道可以加更多仓位
- 跌破隧道，反弹（反抽），不能再做多，减仓
- 上涨趋势内，小周期服从大周期
- 要在小周期上止损，大周期上止盈

同花顺设置：

- EMA21  颜色17
- EMA144 颜色12
- EMA169 颜色10

## MACD 指标

- 0 上金叉强势涨
- 0 上死叉看回调
- 0 下金叉看反弹
- 0 下死叉弱势跌
- 0 轴支撑看压力

红绿柱，辅助看金叉死叉
- 死叉，红->绿
- 金叉，绿->红
- 逐渐远离 0 轴代表能量的加大，逐渐靠近 0 轴代表能量的减少
- 钝化（红绿柱逐渐形成一个碗型），代表能量的暂歇或反转的开始

备注：

- 结合短期EMA均线（13 21），同时金叉可以买，同时死叉可以卖

## 布林带（卖出指标）

- 参数 
  - 国内ETF 21，1.381
  - 上证50 21，1.72
  - 类别不同，波动率不同，特性参数也不同。但都围绕着斐波那契数列做调整
- 上 中 下 轨
- 上轨找止盈点

## 斐波那契指标

画线：

1. 选取趋势**最低点（震荡期）**和**最高点**
2. 两点画斐波那契回调

备注：

- 趋势不破坏的前提，不能跌破 0.618
- 0.382 可能有支撑加速
- 0.236 弱支撑
- 跌破 0.618，趋势会反转
- **跨周期越大，支撑越有力，回调越小**
- 国外资产回调看 0.618，国内资产看 0.382

## 买入点

1. 埋伏在结构性低位（静待风来）
2. 强势确认之后，突破所有压力位之后（轻仓试单）

## 趋势交易法

- 买入点：
  - 中期买点，55ema
  - 长期买点，1号轨道

- 卖出点：
  - 收盘价（走加速，连续3个收盘价）收在布林带下轨，不卖
）收在布林带上轨，不卖
  - 一旦跌破布林带上轨，卖出
  - 大周期指标（月线）
  - 日线用 MACD KDJ RSI。。。

## 成交量&成交额

- 成交量小但成交额大，反映主力在行动

## KDJ

- 作为情绪指标，观察 K 和 J
  - K>80 J>100 超买
  - K<20 J<0 超卖
- 作为趋势指标，观察三条线
  - 金叉 < 20，上涨趋势中重点关注
  - 死叉 > 80，下跌趋势中重点关注
- 作为能量指标，只观察 J
  - 形态背离，上涨趋势时注意超卖（可能时买点），下跌趋势时注意超买（可能会继续下跌）
  - 能量消耗103原则，J>100 或 J<0 连续3天持续，会有能量消耗

## 箴言

- 市场交易的本质：**概率**
- 市场参与者常被消息驱动的焦虑所困，但真正的交易智慧在于：**价格行为已包含所有市场信息。技术分析的精髓在于精准的入场点与严格的风险控制，以小止损博取高盈亏比**。专注于价格走势本身，方能实现交易的长期可持续性
- 科技板块一直是**市场情绪的重要风向标**，若科技及泛科技板块走势疲软，反弹将难以持续。若行情想持续，则科技必须保持强势
