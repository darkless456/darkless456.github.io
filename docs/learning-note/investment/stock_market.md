# 股市笔记

## 建仓

1. **不要**高密度建仓，间距短，容易被套
2. **分批**建仓，缺乏价格回调时的缓冲空间
3. 技术面确认，需等股价企稳或有明确买入信号

## 波段“高抛低吸”策略

1. 确定波段区间
2. 反弹卖出规则
3. 回调买入规则
4. 止损保护
